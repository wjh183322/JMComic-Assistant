# 禁漫助手 开发文档

当前版本：**v1.4.4**

GitHub：https://github.com/wjh183322/JMComic-Assistant （公开）

发布约定：每升一版单独一个 commit，message 为 `vX.Y.Z：变更摘要`，push 到 `main` 并打 tag `vX.Y.Z`。v1.2 为最初存档；1.2.1–1.2.8 当时没有逐版存档，历史从 v1.2 跳到 v1.2.9，之后按版本逐条提交。

以后每改一版，都在本文件追加一节：版本号、日期、相对上一版改了什么。旧工程包放在 `archives/`。
发给你的 zip 文件名：`jm-assistant-android-版本号.zip`。v1.4.1 及更早的包曾用 `jm-scout-android-版本号.zip`。

## v1.2

日期：2026-09-06

相对更早版本：

- 暗号同时含中文数字和阿拉伯数字时，只按出现顺序拼接阿拉伯数字
- 只有中文数字时仍按中文暗号解析（如「十四小时…六万七千九百四十六条」→ 1467946）
- 查询前访问 `/setting` 拿匿名会话 cookie（不是登录，没有账号）
- 封面 / 内页解乱算法与 hect0x7/JMComic-Crawler-Python 一致
- Windows 工程路径含中文时加 `android.overridePathCheck=true`
- 启动主题改为系统 `Theme.Material.Light.NoActionBar`（不再依赖 MaterialComponents 库）
- 收藏、未导出 / 已导出、逗号导出、JSON 搬家导入

工程包：`archives/jm-scout-v1.2.zip`
